// mods for Claude Code

Small mods that make long sessions easier to follow.

A chime when a long turn finishes, and a live side pane of the files, commands and agents from your session. Add the marketplace once, install either.

> /plugin install session-notes --marketplace pongsixtyfour/mods

Answer y to add the marketplace, then pick a scope.

done-sound

Plays a three-note chime when a long turn finishes, so you can look away while Claude works.

0sabout 1.9s
  • Plays only after a turn of 15 seconds or more
  • Only for the main session, never a subagent
  • Stays silent if you interrupted the turn
  • The chime is generated for this mod. Plays on macOS; on Linux and Windows it uses the system player (untested there)
> /plugin install done-sound --marketplace pongsixtyfour/mods

Install

Add the marketplace the first time you install a mod. After that, either mod installs by name.

In a Claude Code session
/plugin install done-sound --marketplace pongsixtyfour/mods

Answer y to add the marketplace, then pick a scope.

From a shell
claude plugin install done-sound --marketplace pongsixtyfour/mods
In the desktop app

The /plugin command does not run there. Click + next to the prompt box, then Plugins, Add marketplace with pongsixtyfour/mods, then Add plugin.

Each mod has its own tests. Run claude plugin test plugins/<name> in the repo. github.com/pongsixtyfour/mods
